Coral Bay — Dario's Run: an original 3D open-world crime game in three.js. Ex-con wheelman Dario Vega works five jobs for fixer Sal Marchetti in a sun-soaked coastal city — explore on foot and by car, steal and drive cars, dodge traffic and pedestrians, outrun a 0–5 star wanted system with ramming police, fight with fists and a pistol, run taxi fares, and save your progress. HUD with canvas minimap, fully synthesized WebAudio sound, no network at runtime: serve game/ statically and play.

## Run it

```sh
node serve.ts
```
